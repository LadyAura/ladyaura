# Lady Aura · Web mágica de diamond painting

Web responsive con estilo negro + magenta, lista para subir a GitHub Pages.

## 📦 Contenido

- `index.html` · estructura de la página
- `styles.css` · estilos (negro profundo + magenta + dorado)
- `script.js` · lightbox, menú móvil y estrellas
- `assets/` · todas las imágenes en formato webp optimizado

## 🚀 Subir a GitHub Pages

1. Descomprime el ZIP donde quieras tenerlo en tu PC
2. Entra en github.com y crea un repositorio nuevo público llamado `ladyaura`
3. Click en "uploading an existing file" y arrastra TODOS los archivos y la carpeta assets
4. Commit changes
5. Settings → Pages → Branch: main → Save
6. Tu URL: `https://TU-USUARIO.github.io/ladyaura/`

## 🛒 Cómo funcionan los pedidos

Cuando un cliente clica "Comprar":
- Se abre Gmail en el navegador con un email pre-rellenado a tu correo
- El asunto incluye el nombre del cuadro
- El cuerpo incluye plantilla con: nombre completo, dirección, CP+ciudad, teléfono
- El cliente solo tiene que completar sus datos y enviar
- Tú recibes el pedido en lady.aura.2025@gmail.com y le contestas con los datos para el pago
