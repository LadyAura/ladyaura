## 🚀 Subir a GitHub Pages

1. Descomprime el ZIP donde quieras tenerlo en tu PC
2. Entra en github.com y crea un repositorio nuevo público llamado `ladyaura`
3. Click en "uploading an existing file" y arrastra TODOS los archivos y la carpeta assets
4. Commit changes
5. Settings → Pages → Branch: main → Save
6. Tu URL: `https://TU-USUARIO.github.io/ladyaura/`

## 📨 Cómo funcionan las pre-reservas

Cuando una clienta clica "Pre-reservar":
- Se abre Gmail con un email pre-rellenado a tu correo
- Asunto: "Pre-reserva Lady Aura - [nombre del cuadro]"
- Cuerpo simple: nombre + email (sin pedir dirección ni datos sensibles)
- Tú recibes la pre-reserva en lady.aura.2025@gmail.com
- Cuando abras oficialmente la tienda, contactas a las personas de la lista de espera

## 🔄 Para activar el modo "Tienda abierta" cuando estés lista

Cuando ya estés dada de alta como autónoma:
1. Cambiar todos los botones "Pre-reservar" por "Comprar"
2. Cambiar banner pre-apertura por banner de envío gratis
3. Activar Stripe Payment Links en cada botón
4. Añadir aviso legal, política de privacidad y condiciones de venta
5. Quitar texto "Pre-reserva sin compromiso" del lightbox
